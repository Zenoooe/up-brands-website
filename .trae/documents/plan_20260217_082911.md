# Performance & Design Fix Plan

We will simultaneously fix the "different font weight" visual bug and implement the "super fast" loading optimizations.

## 1. Fix Font Weight (Visual Regression)
The Chinese text looks different because I previously removed the "Black" (900) weight for the Chinese font to save space. However, your design explicitly uses `font-black` for the main tagline.
*   **Action**: Restore `@fontsource/noto-sans-sc/900.css` in `src/main.tsx`. This will make the Chinese headline ultra-bold again, matching the original design.

## 2. "Super Fast" Loading Optimizations
To achieve the speed you requested without breaking the design again:

### A. Responsive Images (Major Speedup)
Currently, we load full-sized images or fixed 600px width images everywhere.
*   **Action**: Create a `<ResponsiveImage>` component.
*   **Logic**: It will use Supabase's image transformation to serve:
    *   Small images (400px) for mobile.
    *   Medium images (800px) for tablets.
    *   Large images (1200px) for desktop.
    *   Next-gen format (`WebP`) for all.

### B. Lazy Motion (Bundle Size Reduction)
*   **Action**: Use `LazyMotion` in `App.tsx`. This strips out ~30KB of physics animation code from the initial load, only loading it when animations actually happen.

### C. Resource Hinting
*   **Action**: Add `fetchPriority="high"` to the first project image on the homepage so it loads immediately.

## Execution Steps
1.  **Main Entry**: Restore font import in `src/main.tsx`.
2.  **App Config**: Implement `LazyMotion` in `src/App.tsx`.
3.  **UI Component**: Create `src/components/ui/ResponsiveImage.tsx`.
4.  **Homepage**: Replace `img` tags with `<ResponsiveImage>` in `src/pages/Home.tsx`.
