# Emergency Rollback Plan: Restore Image Loading

The integration with Cloudflare CDN has failed, causing all images to break (404 errors). We need to immediately revert the code to load images directly from Supabase again.

## Root Cause
The `src/utils/image.ts` file is forcing a rewrite of all Supabase URLs to `cdn.up-brands.com`. Since the Cloudflare Worker/DNS configuration is not working as expected, these rewritten URLs are dead.

## Solution
We will disable the CDN rewrite logic in `src/utils/image.ts`. This will make the application request images directly from `supabase.co` again, which we know works (albeit consuming bandwidth).

## Execution Steps
1.  **Modify `src/utils/image.ts`**: Comment out or remove the CDN URL replacement logic. The function should simply append the width/quality parameters to the original Supabase URL.
2.  **Verify**: Confirm that image URLs in the app revert to `https://[project-id].supabase.co/...`.

This is a safe, low-risk rollback to restore functionality immediately. We can revisit CDN optimization later in a non-production environment.
